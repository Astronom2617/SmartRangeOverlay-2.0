# Smart Range Overlay 2.0 (Stardew Valley 1.6)

A modern, highly optimized C# mod for Stardew Valley that displays real-time coverage grids for farming tools and objects.

## 🚀 Key Features
* **Smart Farming:** Visual ranges for Sprinklers, Scarecrows, Bee Houses, and Lightning Rods.
* **Demolition Safety:** Dynamic red danger zones for held and active (ticking) bombs.
* **Tool Trajectories:** Directional overlays for Watering Can and Hoe based on upgrade level.
* **Performance:** Built from scratch using modern SMAPI events for zero lag.

## 🛠 Requirements
* [Stardew Valley 1.6+](https://www.stardewvalley.net/)
* [SMAPI 4.0.0+](https://smapi.io/)
* [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) (Optional but recommended)

## 📦 Installation
1. Install the latest version of SMAPI.
2. Download this mod from [Nexus Mods](ВАША_ССЫЛКА_ПОЯВИТСЯ_ПОСЛЕ_ПУБЛИКАЦИИ).
3. Extract the ZIP into your `Stardew Valley/Mods` folder.
4. Play!
